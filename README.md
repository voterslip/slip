## 🌟 प्रमुख विशेषताएँ (Core Features)

1. **🔐 यूजर आईडी व पासवर्ड प्रवेश प्रणाली**:
   - लॉगिन स्क्रीन पर सीधा User ID एवं Password इनपुट।
   - मुख्य व्यवस्थापक (Super Admin - `admin` / `admin2026`) तथा प्रत्याशी/एजेंट लॉगिन।

2. **📸 नया 'सचित्र मतदाता पर्ची (With Pic)' टैब**:
   - मूल मतदाता पर्ची कटिंग्स (Cuttings) को **A-Z अंग्रेजी वर्णानुक्रम** में सुव्यवस्थित प्रिंट।
   - **9 पर्चियाँ प्रति A4 पेज**: उम्मीदवार विवरण (नाम, पद, चुनाव चिन्ह, स्लोगन, मतदान समय) सहित।
   - **15, 18, 21 पर्चियाँ प्रति A4 पेज**: अधिकतम कागज बचत व सघन वितरण लेआउट।
   - **58mm / 80mm थर्मल ब्लूटूथ प्रिंट**: 15, 18, 21 पर्ची बैच कटिंग के साथ मोबाइल प्रिंटिंग।
   - **Google Sheet से नियंत्रण**: `Can_With_Pic_Slips` चेकबॉक्स द्वारा यूजर अनुमति प्रबंधन।

3. **📊 Google Sheet 1-क्लिक ऑटो-सेटअप (`Code.gs`)**:
   - Google Sheet में `Code.gs` पेस्ट करके `initialSetup` रन करें।
   - सभी चेकबॉक्स, अनुमतियाँ, डिफ़ॉल्ट खाते व सेटिंग्स एक बार में स्वतः निर्मित।
